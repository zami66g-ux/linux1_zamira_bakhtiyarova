# Navigation in Bash

## cd

cd to change directory

```bash
cd dir1 # jump into dir1
cd .. #jumpt back to parent directory
```

## Relative paths

Files and folders are relative to where you are right now

```bash
cd dir1/subdir # jumps into dir1 and then into subdir
```

## Absolute paths

Starts from the root /

ex
```bash
cd/home/user/Documents
